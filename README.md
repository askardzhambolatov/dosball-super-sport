# DOSBALL Super Sport International

Official project repository for the DOSBALL Super Sport International ecosystem.

## Project scope

This repository is a structured starter package for the DOSBALL digital ecosystem, including:

- DOSBALL sport presentation
- Federation membership
- Video game subscription concept
- Clubs and coaches
- Three professional leagues
- International competitions
- Academy of Succession and career progression
- Referral and product promotion logic
- Franchise progression
- Transparent voluntary charity
- Inheritance / succession principles for eligible member accounts
- Government and education cooperation
- Anti-gambling policy

## Quick start

This starter runs as a simple static website.

1. Download or clone the repository.
2. Open `index.html` in a browser.
3. For GitHub Pages, enable Pages in the repository settings and publish from the `main` branch.

## Repository structure

- `index.html` — main website
- `styles.css` — responsive styles
- `app.js` — small navigation and content helpers
- `data/site-content.json` — editable project data
- `docs/` — product, ecosystem, governance, academy and roadmap documentation
- `assets/images/` — place official logos, uniforms and sport visuals here

## Important

This package is a project starter and presentation framework. Financial, legal, franchise, reward, inheritance, charity and membership mechanisms should be reviewed and adapted to the laws of each country before public launch.

DOSBALL does not support betting, wagering, lotteries, gambling or gambling-related activity.
